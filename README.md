# C Programming Exercises & Assignments

This repository contains my C programming practice files, assignments, and coursework.

## 🛠️ Languages and Tools
* **Language:** C
* **Compiler:** GCC
* **Editor:** Visual Studio Code

## 📁 What's Included
* **Assignment2.c** - Student score calculation program.
* **CAT2.c / CAT3.c** - Course assessment test exercises.
* Practice scripts covering loops, arithmetic operations, and arrays.

## 🚀 How to Run
1. Open terminal or command prompt.
2. Compile any `.c` file using GCC:
   `gcc Assignment2.c -o Assignment2`
3. Run the executable:
   `./Assignment2`
